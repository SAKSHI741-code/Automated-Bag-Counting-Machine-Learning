# Automated-Bag-Counting-on-Trucks-using-Machine-Learning

 - Developed an automated prototype solution to streamline the bag-counting process in trucks, significantly reducing manual effort and processing time.
 - This involved curating and annotating a dataset of video frames to train a robust YOLOv8 object detection model.
 - The model achieved an impressive 87 mAP in detecting and counting bags in real-time, even under varying environmental conditions.
 - To demonstrate usability, the solution was deployed as a web application using Streamlit, enabling real-time inference and visualization through a user-friendly interface.
